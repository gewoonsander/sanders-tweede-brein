# Too Many Productivity Tool Subscriptions?

- **Video:** https://www.youtube.com/watch?v=OBuLLxUAF6Y
- **Ondertitel-taal:** en
- **Bron:** Firecrawl (YouTube-verwerker)

---

If you complain that the tool is too
expensive, then you have no clue why you
use the tool in the first place. Because
if you recognize why you're using a
productivity tool and why you're paying
for it, you will also realize all the
time it's saving you that you can use to
be more productive, to earn more money,
to climb the ladder, to take on more
opportunities. And then I tell you, $50,
$100 per month, it's a joke compared to
what you will retrieve in time using
these tools properly. But it starts with
understanding why you use the tools in
the first place. So if you have a list
of tools with a lot of subscriptions and
you are annoyed every month seeing the
payments, kill all of them. Step back,
use piece of paper and start thinking
again. Why do you use these tools? How
does it help? or if you're uncertain,
stop using the tool for a week and see
if it hurts and if you become less
productive in order to start
appreciating these things. But guys,
let's stop the discussion about oh no,
not another subscription that's too
expensive.
